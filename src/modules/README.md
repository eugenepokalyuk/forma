# modules — доменные модули

Вся логика приложения, разложенная по доменам. Экраны (`pages/`) собираются из модулей.

| Модуль     | Домен                                               |
| ---------- | --------------------------------------------------- |
| `auth`     | вход, текущий пользователь, профиль                 |
| `programs` | каталог, программы пользователя, реакции            |
| `workout`  | активная тренировка и офлайн-синхронизация подходов |
| `social`   | лента, лайки, комментарии, подписки                 |
| `bro`      | Фитнес Бро: реплики, статистика, вода, ачивки       |

## Устройство модуля

```
api/         по одной функции на эндпоинт: <имя>Api.ts
models/      типы ответов бэка
queries.ts   react-query: ключи кэша (<домен>Keys) и хуки
store.ts     zustand — только клиентское состояние, без сети
services/    сценарии: меняют стор, ставят операции в очередь, ходят в api
hooks/       React-обёртки сценариев (диалоги, навигация)
helpers/     чистые функции домена
components/  компоненты домена, нужные нескольким экранам
index.ts     публичный API модуля
```

Не у каждого модуля есть все папки — только нужные.

## Правила

- Снаружи — только `import { … } from '@/modules/<домен>'`; внутри модуля — относительные пути.
- Модули импортируют друг друга только через `index.ts`; циклов нет:
  `bro → auth, programs, workout`, `auth → workout`, `workout → programs`.
- Серверные данные — через `queries.ts`, клиентское состояние — в `store.ts`.
