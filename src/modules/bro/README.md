# bro — Фитнес Бро

Реплики-подсказки на главной — порт логики сайта (forma-next, `broMessages`).

- `helpers/broMessages.ts` — подбор реплик: стрик, похвала, ачивки, цель недели, условные фразы из админки
- `queries.ts` — фразы, статистика, вода за сегодня, ачивки; ключи — `broKeys`
- `components/TipsCarousel` — карусель реплик
