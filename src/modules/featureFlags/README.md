# featureFlags — фича флаги

Функции, которые включаются и выключаются в админке → «Фича флаги» без релиза.

- `queries.ts` — `useFeatureFlag(key)`: `true`, если флаг включён; пока флаги не загружены
  или флага нет на бэке — `false`. Список кэшируется на устройстве, как остальные запросы
- `models/` — `FeatureFlagKey`: ключи флагов, которые знает приложение

| Ключ             | Что включает                                        |
| ---------------- | --------------------------------------------------- |
| `catalog_gender` | переключатель «Мужская» / «Женская» вверху каталога |

Новый флаг: добавить его в админке, ключ — в `FeatureFlagKey` и в эту таблицу.
