# Auth — вход

- `Email` — ввод почты, отправка кода. «Войти» всегда активна и жёлтая — главное действие экрана; с неверной почтой по нажатию рамка поля краснеет и поле трясётся (`Input` с `error` и `shakeKey`); «Войти без сохранения прогресса» открывает `GuestSheet` — объяснение гостевого режима и вход после согласия
- `Code` — ввод шестизначного кода, повторная отправка, `signIn`
