# pages — экраны

Экран = композиция из модулей и `shared/ui`. Маршруты в `app/` только реэкспортируют отсюда.

```
<Экран>/
  <Экран>.tsx   экран (default export)
  components/   компоненты, нужные только этому экрану
  hooks/        логика экрана, не нужная другим
```

- Компонент или хук понадобился второму экрану — переносим в модуль (`modules/<домен>/components`)
  или в `shared/ui`, если он не знает о домене.
- Экран держим тонким: секции сами берут данные через хуки модулей, у разных
  состояний (пусто / список / ошибка) — отдельные view.
