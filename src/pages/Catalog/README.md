# Catalog — каталог программ

Список программ с бэка: закреплённая preview-программа баннером сверху,
остальные — широкими и средними карточками (`components/`), порядок задаётся в админке.

При включённом фича флаге `catalog_gender` под шапкой — переключатель «Мужская» / «Женская»
(`components/CatalogGenderSwitch`): весь каталог, включая закреплённую программу, фильтруется
по опциям программы из админки; программа с обеими опциями — в обеих вкладках. Выбор запоминается.

Шапка с переключателем закреплена над списком; обложка закреплённой программы (высота 350) —
первым элементом списка под ней, без параллакса и не заходит под статус-бар.
