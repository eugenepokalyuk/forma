# Catalog — каталог программ

Список программ с бэка: закреплённая preview-программа баннером сверху,
остальные — широкими и средними карточками (`components/`), порядок задаётся в админке.

У обложки — параллакс при прокрутке. Шапка закреплена: с обложкой — `FloatingHeader` поверх
списка (фон проявляется, когда обложка уехала), без неё — над списком.
