# Profile — профиль

Секции: карточка пользователя, итоги (серия, тренировки, тоннаж), аккаунт
(друзья, заблокированные, тариф, «только друзьям»), «Предложить идею»
(шторка с текстом и картинкой → админка) и правовые документы,
выход с предупреждением о несинхронизированных данных и удаление аккаунта.

Гостю под карточкой — `GuestSection`: «Прогресс не сохранён» и привязка почты
(`SaveProgressSheet`: почта → код; как на экране входа — неверная почта краснеет рамкой и
трясёт поле, ошибки сервера и сети — тостом поверх шторки). Строка «Удалить аккаунт» гостю не показывается —
его выход и есть удаление.
