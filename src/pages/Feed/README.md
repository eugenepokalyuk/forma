# Feed — лента

Посты о тренировках: карточка (`PostCard`) с пейджером «фото / упражнения»,
лайк по даблтапу, комментарии в модалке (`CommentsModal`). Данные — `modules/social`.

Чужой контент: «…» у поста и долгое нажатие на комментарий — жалоба (`ReportSheet`)
или блокировка автора (`hooks/useContentActions`).
