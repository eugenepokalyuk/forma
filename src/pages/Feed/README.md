# Feed — лента

Вертикальная карусель постов: пост на страницу со снэпом (`PostPage` — масштаб и прозрачность
соседей), щелчок вибрацией при перелистывании; шапка закреплена над списком.
Карточка (`PostCard`) заполняет высоту страницы: медиа-пейджер «фото / упражнения» забирает
свободное место, подпись — до трёх строк. Лайк по даблтапу, комментарии в шторке
(`CommentsModal`, поле — `Composer`). Данные — `modules/social`.

Чужой контент: «…» у поста и долгое нажатие на комментарий — жалоба (`ReportSheet`)
или блокировка автора (`hooks/useContentActions`).
