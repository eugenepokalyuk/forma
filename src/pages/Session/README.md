# Session — режим выполнения

Полноэкранная тренировка: упражнение → ввод подхода → отдых → … → итог.

- `Session.tsx` — переключение фаз (упражнение / отдых / итог) и переходы между упражнениями
- `components/` — карточки упражнения, ввод (вес и повторы или время), подходы (`SetPills`),
  экран отдыха с таймером, заметка к подходу, итог тренировки

Все действия — через сервисы `modules/workout`, сеть ничего не блокирует.
