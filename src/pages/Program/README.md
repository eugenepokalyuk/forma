# Program — страница программы

Сверху — обложка как у закреплённой программы в каталоге (`ProgramPreviewCard`), вместо реакций
на ней кнопка: «Начать тренировку» добавляет программу в «Мои программы» (ПРО без доступа —
`showProInfo`), «Отписаться от программы» убирает её оттуда. Ниже, на заходящей на обложку
секции, — описание, реакции, переключатель недель и тренировки недели (`WorkoutListItem`,
запуск через `useStartWorkout`).

Текущий день — следующая по плану тренировка (`getProgramProgress` из `workout`, та же логика,
что «Сегодня» на главной): выделен рамкой и меткой «Сегодня», раскрыт, страница открывается на
его неделе. Пройденные в текущем круге дни — с галочкой. У программы, которую не добавляли и не
проходили, ничего не выделяется.
