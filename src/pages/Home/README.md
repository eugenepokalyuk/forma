# Home — главная

Секции-контейнеры, каждая сама берёт свои данные:
`WeekSection` (неделя тренировок),
`BroSection` (реплики Бро и цель недели), `ProgramsSection` (мои программы или призыв выбрать).

`hooks/` — программы пользователя, префетч активных программ, даты тренировок,
контекст «сегодня» (следующая тренировка и её старт), тост о несинхронизированных
операциях (`useSyncToast` — поверх экрана, раскладку не сдвигает).
