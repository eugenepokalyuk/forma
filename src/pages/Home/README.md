# Home — главная

Секции-контейнеры, каждая сама берёт свои данные:
`WeekSection` (неделя тренировок),
`BroSection` (реплики Бро и цель недели), `ProgramsSection` (мои программы или призыв выбрать).
Шапка закреплена над прокруткой (`ScreenContainer header`).

Неделя — выбор дня: тап по дню, стрелки и свайп по полосе листают недели (тот же день недели),
«Сегодня» возвращает к текущему. Назад — до недели первой тренировки, вперёд — только следующая
неделя. Бро и старт тренировки — только сегодня; выбранный день держит `Home`:
- прошедший — `views/PastDayView`: его тренировки карточками `SessionDayCard` (выполнена или нет,
  подходы, тоннаж, время, сделанное по упражнениям) или «Тренировки не было»;
- будущий — `views/FutureDayView`: следующая по плану тренировка активной программы, без старта
  (тренировки идут очередью программы, а не по датам).

Мои программы — свои карточки `HomeProgramCard` (Liquid Glass): название, «Начать тренировку»
(следующая по плану, или «Продолжить», если она идёт) и карандаш — на страницу программы, где
можно выбрать другой день; под разделителем — упражнения этого дня (`WorkoutExercises`).

`hooks/` — программы пользователя, префетч активных программ, даты тренировок,
контекст «сегодня» (следующая тренировка и её старт), тост о несинхронизированных
операциях (`useSyncToast` — поверх экрана, раскладку не сдвигает).
