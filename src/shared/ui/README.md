# ui — дизайн-система

Компоненты без доменной логики, импорт — `@/shared/ui`.
Типографика, иконки, кнопки, поля ввода, карточки, строки списков, секции,
плитки статистики, кольцо прогресса, контейнер экрана, таб-бар, аватар,
шторка снизу (`BottomSheet` — для всех модалок-шторок).

Кнопки (`Button`, круглые `GlassIconButton`) на iOS 26+ — нативное стекло Liquid Glass
(`glass.ts`, `expo-glass-effect`) без заливки под ним — иначе стекло выглядит плоским;
на Android и старых iOS — обычная заливка.
Стекло не рисуется, если создаётся внутри полупрозрачного родителя, поэтому экраны с кнопками
появляются через `FadeInCover` (растворяется слой цвета фона), а не через opacity самого экрана.

Цвета, отступы и шрифты — только из `theme`.
