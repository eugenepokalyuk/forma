# lib — утилиты

- `queryClient.ts` — react-query: кэш на 7 дней, сохраняется в MMKV; `connectQueryClientToDevice`
  (из корневого layout) сообщает ему о сети (NetInfo) и возврате в приложение (AppState) —
  офлайн-запросы ждут сети и перезапрашиваются, когда она появилась; мутации без сети сразу падают
- `storage/` — MMKV (быстрое хранилище сторов и кэша) и токен в SecureStore
- `date/` — неделя (любая по сдвигу от текущей — `getWeek`, `weekOffsetOf`), «2 часа назад», время суток по часовому поясу
- `string/` — числа (мм:сс, разряды, тоннаж) и склонения
- `hooks/` — общие хуки: `useTimeOfDay`, `useRefresh` (pull-to-refresh), `useDebouncedValue`
- `media/` — выбор фото из галереи (`pickImages`) и сжатие до 1080px в WebP (`compressImage`);
  без нативного модуля в сборке пикер возвращает пусто, а сжатие — исходный файл
- `alerts/` — `alertActionFailed`: «Не удалось …» с советом проверить сеть; его зовут
  мутации модулей, поэтому он здесь, а не в `ui` (логика модулей не тянет `@/shared/ui`)
- `uuid.ts` — id операций и подходов
