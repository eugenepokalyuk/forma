# shared — общее, не знающее о доменах

| Папка        | Что                                                                            |
| ------------ | ------------------------------------------------------------------------------ |
| `api/`       | HTTP-клиент: `apiRequest`, базовый URL, обработчик 401                         |
| `ui/`        | дизайн-система: текст, кнопки, поля, каркас экрана, карточки, шторки и тосты   |
| `lib/`       | утилиты: queryClient, хранилища, даты, строки, медиа, алерты, общие хуки, uuid |
| `constants/` | `ROUTES` — все пути навигации                                                  |

Правило: `shared` **не импортирует** `modules` и `pages`. Если коду нужен домен — ему место в модуле.
