# api — HTTP-клиент

- `apiRequest<R>(config)` — единая точка запросов, возвращает тело ответа; подставляет токен, на 401 стирает его
- `getApiBase` — базовый URL (`EXPO_PUBLIC_API_URL`, по умолчанию прод)
- `unauthorized.ts` — обработчик 401 (его ставит `modules/auth`: переводит в «не вошёл»)

Эндпоинты живут в `modules/<домен>/api`, не здесь.
