# theme — токены дизайна

- `palette.ts` — сырая палитра
- `colors.ts` — семантические цвета (`COLORS.Text.primary`, `COLORS.Surface.accent`…) — в компонентах только они
- `tokens.ts` — отступы, радиусы, тени, анимации, градиенты, размеры зон нажатия
- `typography.ts` — варианты текста для `Typography`

Импорт — `@/theme`. Значения цветов и размеров в компонентах не хардкодим.
