# app — маршруты expo-router

Файловая структура этой папки и есть навигация приложения: каждый `.tsx` — экран-маршрут,
`_layout.tsx` — обёртка группы (Stack/Tabs) и гейты доступа.

Здесь **нет логики и вёрстки экранов**: файл маршрута только реэкспортирует экран из `pages/`:

```ts
export { default } from '@/pages/Home/Home';
```

Компоненты и хелперы сюда класть нельзя — expo-router примет любой `.tsx` за маршрут.

| Путь          | Что                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| `_layout.tsx` | корень: шрифты, splash, восстановление сессии, `bootstrap()` авторизации, синхронизация очереди, слой тостов |
| `index.tsx`   | стартовый редирект: вход → активная тренировка → главная                                                     |
| `(auth)/`     | вход по email и коду                                                                                         |
| `(app)/`      | приложение для вошедшего пользователя: вкладки и вложенные экраны                                            |
| `session/`    | режим выполнения тренировки                                                                                  |

Пути маршрутов для `router.push`/`Redirect` — только через `ROUTES` из `shared/constants/routes.ts`.
